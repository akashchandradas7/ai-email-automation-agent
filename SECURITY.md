## Reporting a Vulnerability

We take the security of this AI automation agent and its integrations seriously. If you discover a security vulnerability, please report it responsibly.

### How to Report

- **Email:** Send details directly to **Akash Chandra Das** at `akashcdasbd@gmail.com`.
- **Subject:** `[SECURITY] AI Email Automation Agent Vulnerability Report`
- **Please Include:**
  - Description of the vulnerability and potential impact.
  - Step-by-step reproduction steps or proof-of-concept (PoC).
  - Any suggested remediation or mitigation.

### Response Timelines

- **Initial Acknowledgment:** Within 24–48 hours.
- **Triage & Status Update:** Within 5 business days.
- **Fix & Disclosure:** Once a fix is verified and deployed.

> Please do **NOT** open public GitHub issues for security vulnerabilities or credential disclosures.
